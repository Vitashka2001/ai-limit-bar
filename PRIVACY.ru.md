# Приватность

[English](PRIVACY.md) · [Українська](PRIVACY.uk.md) · [Русский](PRIVACY.ru.md)

AI Limit Bar работает на Mac пользователя и не обращается ни к какому собственному серверу.

Приложение:

- не собирает аналитику или телеметрию;
- не использует собственный сервер;
- не читает и не сохраняет пароли, cookies, session storage или API-ключи;
- не запрашивает доступ к вводу с клавиатуры, записи экрана, микрофону, камере или файлам пользователя;
- получает аккаунт и лимиты Codex через локальный `codex app-server`;
- когда включено **Автообновление Claude**, запрашивает лимиты Claude у Anthropic через `api.anthropic.com/api/oauth/usage`, используя вход самого Claude Code, как описано ниже;
- получает проценты лимитов Claude Code и время их сброса через официальный локальный интерфейс `statusLine`;
- может пассивно читать локальный кэш Claude Desktop `plan-usage-history.json` с процентами, временем обновления и несекретным ID организации;
- может пассивно читать запись `cachedUsageUtilization`, которую сам Claude Code хранит в `~/.claude.json`, с процентами, временем сброса и несекретным ID аккаунта. Остальная часть этого файла не используется.

## Живые лимиты Claude

Локальные кэши Claude обновляются лишь примерно раз за промпт, поэтому во время долгой работы агента они стоят на месте. Чтобы показывать актуальные цифры, AI Limit Bar примерно раз в минуту запрашивает Anthropic напрямую — тем же запросом, что и команда `/usage` в Claude Code.

Для аутентификации этого запроса AI Limit Bar читает элемент `Claude Code-credentials` из связки ключей входа через `/usr/bin/security` — тот же инструмент, которым Claude Code его сохраняет, поэтому диалог связки ключей не появляется. Элемент перечитывается перед каждым запросом, потому что Claude Code заменяет его каждый раз, когда обновляет вход. Из этого элемента используется только access token: он держится в памяти на время одного запроса и отправляется только на `api.anthropic.com`. Refresh token из того же элемента никогда не используется: обновление входа здесь ротировало бы его в обход Claude Code и разлогинило бы Claude Code. Когда access token просрочен, живые запросы приостанавливаются, пока Claude Code его не обновит, а вместо них показываются локальные источники ниже. Ничего из элемента не записывается на диск и не попадает в журналы.

Ответ содержит только проценты использования и время сброса; AI Limit Bar держит последний из них в памяти и не записывает его на диск. Если Anthropic отвечает ограничением частоты, приложение ждёт столько, сколько просит сервер, увеличивая паузу до 15 минут.

Выключение **Автообновления Claude** полностью останавливает эти запросы.

## Локальные источники Claude

Когда включено **Автообновление Claude**, AI Limit Bar также добавляет команду в `~/.claude/settings.json` вместе с официальной опцией Claude Code `refreshInterval`, поэтому строка статуса перезапускается каждые 30 секунд, пока открыта терминальная сессия. Claude Code передаёт ей обычный JSON строки статуса. AI Limit Bar сохраняет только проценты двух лимитов, время их сброса, время получения и последнего изменения. Session ID, пути проектов, запросы, ответы и контекст модели не сохраняются.

Кэш Claude Desktop не содержит email, типа тарифа или времени сброса, поэтому AI Limit Bar берёт их из других источников. Все источники объединяются по окнам, побеждает самое свежее значение. Данные остаются видимыми и участвуют в выборе индикатора независимо от возраста, потому что лимит не меняется, пока Claude простаивает; окно, время сброса которого прошло, снова показывается пустым. AI Limit Bar не запускает, не скрывает и не завершает Claude Desktop.

Чтобы решить, какой сервис показывать, AI Limit Bar запоминает в собственных настройках последние увиденные проценты каждого сервиса и время, когда они в последний раз выросли.

## Прочее

При смене аккаунта Codex открывается официальный процесс авторизации в браузере. Новый аккаунт становится активным для остальных локальных инструментов Codex на этом Mac.

Пользователь может остановить весь опрос через **Мониторинг лимитов** или закрыть приложение через **Полностью выключить**.
