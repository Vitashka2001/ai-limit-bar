# Приватность

[English](PRIVACY.md) · [Українська](PRIVACY.uk.md) · [Русский](PRIVACY.ru.md)

AI Limit Bar полностью работает на Mac пользователя.

Приложение:

- не собирает аналитику или телеметрию;
- не использует собственный сервер;
- не читает и не сохраняет пароли, cookies, session storage, access token, refresh token или API-ключи;
- не запрашивает доступ к вводу с клавиатуры, записи экрана, микрофону, камере или файлам пользователя;
- получает аккаунт и лимиты Codex через локальный `codex app-server`;
- получает проценты лимитов Claude Code и время их сброса через официальный локальный интерфейс `statusLine`;
- может пассивно читать локальный кэш Claude Desktop `plan-usage-history.json` с процентами, временем обновления и несекретным ID организации;
- может пассивно читать запись `cachedUsageUtilization`, которую сам Claude Code хранит в `~/.claude.json`, с процентами, временем сброса и несекретным ID аккаунта. Остальная часть этого файла не читается.

Когда включено **Автообновление Claude**, AI Limit Bar добавляет команду в `~/.claude/settings.json` вместе с официальной опцией Claude Code `refreshInterval`, поэтому строка статуса дополнительно перезапускается каждые 30 секунд, пока сессия открыта. Claude Code передаёт ей обычный JSON строки статуса. AI Limit Bar сохраняет только проценты двух лимитов, время их сброса, время получения и последнего изменения. Session ID, пути проектов, запросы, ответы и контекст модели не сохраняются.

Кэш Claude Desktop не содержит email, типа тарифа или времени сброса, поэтому AI Limit Bar берёт их из двух других локальных источников. Три источника объединяются по окнам, побеждает самое свежее значение. Данные остаются видимыми и участвуют в выборе индикатора независимо от возраста, потому что лимит не меняется, пока Claude простаивает; окно, время сброса которого прошло, снова показывается пустым. AI Limit Bar не запускает, не скрывает и не завершает Claude Desktop.

При смене аккаунта Codex открывается официальный процесс авторизации в браузере. Новый аккаунт становится активным для остальных локальных инструментов Codex на этом Mac.

Пользователь может остановить весь опрос через **Мониторинг лимитов** или закрыть приложение через **Полностью выключить**.
