# Приватность

[English](PRIVACY.md) · [Українська](PRIVACY.uk.md) · [Русский](PRIVACY.ru.md)

AI Limit Bar полностью работает на Mac пользователя.

Приложение:

- не собирает аналитику или телеметрию;
- не использует собственный сервер;
- не читает и не сохраняет пароли, cookies, session storage, access token, refresh token или API-ключи;
- не запрашивает доступ к вводу с клавиатуры, записи экрана, микрофону, камере или файлам пользователя;
- получает аккаунт и лимиты Codex через локальный `codex app-server`;
- получает проценты лимитов Claude Code и время их сброса через официальный локальный интерфейс `statusLine`;
- может пассивно читать локальный кэш Claude Desktop `plan-usage-history.json` с процентами, временем обновления и несекретным ID организации.

Когда включено **Автообновление Claude**, AI Limit Bar добавляет команду в `~/.claude/settings.json`. После ответов Claude Code может передавать ей обычный JSON строки статуса. AI Limit Bar сохраняет только проценты двух лимитов, время их сброса, время получения и последнего изменения. Session ID, пути проектов, запросы, ответы и контекст модели не сохраняются.

Кэш Claude Desktop не содержит email, типа тарифа или времени сброса. Данные старше пяти минут остаются видимыми, но не используются для автоматического выбора индикатора. Если свежие данные Claude Code недоступны, автообновление может запустить Claude Desktop без активации, скрыть его и при необходимости вернуть фокус предыдущему приложению. AI Limit Bar отслеживает точный процесс, который запустила сама, и завершает его после получения свежих данных или через 30 секунд. Уже работающий Desktop приложение не запускает и не закрывает, а при отсутствии Desktop пропускает резервное обновление.

При смене аккаунта Codex открывается официальный процесс авторизации в браузере. Новый аккаунт становится активным для остальных локальных инструментов Codex на этом Mac.

Пользователь может остановить весь опрос через **Мониторинг лимитов** или закрыть приложение через **Полностью выключить**.
