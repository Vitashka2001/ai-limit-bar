# Приватність

[English](PRIVACY.md) · [Українська](PRIVACY.uk.md) · [Русский](PRIVACY.ru.md)

AI Limit Bar повністю працює на Mac користувача.

Застосунок:

- не збирає аналітику або телеметрію;
- не використовує власний сервер;
- не читає й не зберігає паролі, cookies, session storage, access token, refresh token або API-ключі;
- не запитує доступ до введення з клавіатури, запису екрана, мікрофона, камери або файлів користувача;
- отримує обліковий запис і ліміти Codex через локальний `codex app-server`;
- отримує відсотки лімітів Claude Code і час їх скидання через офіційний локальний інтерфейс `statusLine`;
- може пасивно читати локальний кеш Claude Desktop `plan-usage-history.json` із відсотками, часом оновлення та несекретним ID організації.

Коли ввімкнено **Автооновлення Claude**, AI Limit Bar додає команду до `~/.claude/settings.json`. Після відповідей Claude Code може передавати їй звичайний JSON рядка стану. AI Limit Bar зберігає лише відсотки двох лімітів, час їх скидання, час отримання й останньої зміни. Session ID, шляхи проєктів, запити, відповіді та контекст моделі не зберігаються.

Кеш Claude Desktop не містить email, типу плану або часу скидання. Дані, старші за п'ять хвилин, залишаються видимими, але не використовуються для автоматичного вибору індикатора. Якщо свіжі дані Claude Code недоступні, автооновлення може приховано запустити Claude Desktop. AI Limit Bar відстежує точний процес, який запустив сам, і завершує його після отримання свіжих даних або через 30 секунд. Уже запущений користувачем Claude Desktop застосунок не закриває.

Під час зміни облікового запису Codex відкривається офіційний процес авторизації в браузері. Новий обліковий запис стає активним для інших локальних інструментів Codex на цьому Mac.

Користувач може зупинити все опитування через **Моніторинг лімітів** або закрити застосунок через **Повністю вимкнути**.
