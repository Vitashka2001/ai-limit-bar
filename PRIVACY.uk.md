# Приватність

[English](PRIVACY.md) · [Українська](PRIVACY.uk.md) · [Русский](PRIVACY.ru.md)

AI Limit Bar повністю працює на Mac користувача.

Застосунок:

- не збирає аналітику або телеметрію;
- не використовує власний сервер;
- не читає й не зберігає паролі, cookies, session storage, access token, refresh token або API-ключі;
- не запитує доступ до введення з клавіатури, запису екрана, мікрофона, камери або файлів користувача;
- отримує обліковий запис і ліміти Codex через локальний `codex app-server`;
- читає для Claude лише локальний кеш Claude Desktop `plan-usage-history.json` із відсотками, часом оновлення та несекретним ID організації.

Локальний кеш Claude не містить email, типу плану або часу скидання. Дані, старші за п'ять хвилин, позначаються як кешовані й не використовуються для автоматичного вибору індикатора.

Коли ввімкнено **Оновлювати дані Claude у фоні**, AI Limit Bar може приховано запустити Claude Desktop, щоб офіційний застосунок оновив власний кеш. AI Limit Bar не читає дані сесії Claude та закриває лише той прихований екземпляр Claude, який запустив сам.

Під час зміни облікового запису Codex відкривається офіційний процес авторизації в браузері. Новий обліковий запис стає активним для інших локальних інструментів Codex на цьому Mac.

Користувач може зупинити все опитування через **Моніторинг лімітів** або закрити застосунок через **Повністю вимкнути**.
