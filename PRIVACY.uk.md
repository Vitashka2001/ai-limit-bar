# Приватність

[English](PRIVACY.md) · [Українська](PRIVACY.uk.md) · [Русский](PRIVACY.ru.md)

AI Limit Bar повністю працює на Mac користувача.

Застосунок:

- не збирає аналітику або телеметрію;
- не використовує власний сервер;
- не читає й не зберігає паролі, cookies, session storage, access token, refresh token або API-ключі;
- не запитує доступ до введення з клавіатури, запису екрана, мікрофона, камери або файлів користувача;
- отримує обліковий запис і ліміти Codex через локальний `codex app-server`;
- отримує відсотки лімітів Claude Code і час їх скидання через офіційний локальний інтерфейс `statusLine`;
- може пасивно читати локальний кеш Claude Desktop `plan-usage-history.json` із відсотками, часом оновлення та несекретним ID організації;
- може пасивно читати запис `cachedUsageUtilization`, який сам Claude Code зберігає в `~/.claude.json`, із відсотками, часом скидання та несекретним ID облікового запису. Решта цього файлу не читається.

Коли ввімкнено **Автооновлення Claude**, AI Limit Bar додає команду до `~/.claude/settings.json` разом із офіційною опцією Claude Code `refreshInterval`, тому рядок стану додатково перезапускається кожні 30 секунд, поки сесія відкрита. Claude Code передає їй звичайний JSON рядка стану. AI Limit Bar зберігає лише відсотки двох лімітів, час їх скидання, час отримання й останньої зміни. Session ID, шляхи проєктів, запити, відповіді та контекст моделі не зберігаються.

Кеш Claude Desktop не містить email, типу плану або часу скидання, тому AI Limit Bar бере їх із двох інших локальних джерел. Три джерела об'єднуються по вікнах, перемагає найсвіжіше значення. Дані залишаються видимими й беруть участь у виборі індикатора незалежно від віку, бо ліміт не змінюється, поки Claude простоює; вікно, час скидання якого минув, знову показується порожнім. AI Limit Bar не запускає, не приховує й не завершує Claude Desktop.

Під час зміни облікового запису Codex відкривається офіційний процес авторизації в браузері. Новий обліковий запис стає активним для інших локальних інструментів Codex на цьому Mac.

Користувач може зупинити все опитування через **Моніторинг лімітів** або закрити застосунок через **Повністю вимкнути**.
