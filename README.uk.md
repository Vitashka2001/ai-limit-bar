<h1 align="center">AI Limit Bar</h1>
<p align="center">Ліміти Codex і Claude в рядку меню macOS.</p>
<p align="center"><a href="README.md">English</a> · <strong>Українська</strong> · <a href="README.ru.md">Русский</a></p>

AI Limit Bar показує найактуальніший свіжий ліміт у рядку меню, а після відкриття — усі знайдені ліміти Codex і Claude в одній нативній панелі.

## Можливості

- автоматично стежить за нещодавньою активністю Codex або Claude;
- завжди надає перевагу свіжому критичному ліміту нижче 20%;
- показує всі знайдені 5-годинні й тижневі квоти;
- зелений колір при 50–100%, жовтий при 20–49% і червоний нижче 20%;
- показує обліковий запис Codex і дає змогу його змінити;
- чітко позначає застарілі дані Claude;
- англійська, українська та російська мови;
- ручне оновлення, пауза моніторингу й автозапуск.

## Джерела даних

Дані Codex надходять із локального `codex app-server`. Дані Claude читаються з локального кешу Claude Desktop `plan-usage-history.json`. Застосунок не читає cookies, session storage, паролі, токени або API-ключі.

Claude Desktop має працювати, щоб оновлювати кеш. Кеш не містить часу скидання, тому AI Limit Bar показує час оновлення. Дані, старші за 15 хвилин, залишаються видимими як кешовані, але не обираються для головного індикатора.

## Установлення

Потрібна macOS 13+, Codex для лімітів Codex і Claude Desktop для лімітів Claude. Завантажте `AI-Limit-Bar-2.0.0.dmg` з [останнього релізу](https://github.com/Vitashka2001/ai-limit-bar/releases/latest), перетягніть **AI Limit Bar** до `Applications` і запустіть.

Збірка локально підписана, але не нотаризована. Якщо macOS заблокує перший запуск, натисніть застосунок правою кнопкою, виберіть **Відкрити** й підтвердьте.

## Керування

- **Моніторинг лімітів** призупиняє всі фонові оновлення.
- **Змінити обліковий запис Codex...** відкриває офіційний вхід Codex.
- **Мова** змінює мову інтерфейсу й перезапускає застосунок.
- **Запускати під час входу** керує автозапуском.
- **Повністю вимкнути** закриває застосунок.

Для повного вимкнення зніміть **Запускати під час входу** та виберіть **Повністю вимкнути**. Щоб увімкнути знову, відкрийте застосунок з `Applications`.
