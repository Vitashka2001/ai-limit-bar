<h1 align="center">AI Limit Bar</h1>
<p align="center">Ліміти Codex і Claude в рядку меню macOS.</p>
<p align="center"><a href="README.md">English</a> · <strong>Українська</strong> · <a href="README.ru.md">Русский</a></p>

AI Limit Bar показує найактуальніший свіжий ліміт у рядку меню, а після відкриття — усі знайдені ліміти Codex і Claude в одній нативній панелі.

## Можливості

- автоматично стежить за нещодавньою активністю Codex або Claude;
- показує Codex і Claude поруч, коли обидва були активні протягом поточної 30-хвилинної робочої сесії;
- завжди надає перевагу свіжому критичному ліміту нижче 20%;
- показує всі знайдені 5-годинні й тижневі квоти;
- зелений колір при 50–100%, жовтий при 20–49% і червоний нижче 20%;
- дає змогу змінювати Codex і відкриває налаштування профілю Claude Desktop для зміни облікового запису;
- може ненадовго запускати Claude Desktop у фоні для оновлення кешу лімітів;
- чітко позначає застарілі дані Claude;
- англійська, українська та російська мови;
- ручне оновлення, пауза моніторингу й автозапуск.

## Джерела даних

Дані Codex надходять із локального `codex app-server`. Дані Claude читаються з локального кешу Claude Desktop `plan-usage-history.json`. Застосунок не читає cookies, session storage, паролі, токени або API-ключі.

Коли ввімкнено **Оновлювати дані Claude у фоні**, AI Limit Bar перевіряє локальний кеш щохвилини й ненадовго запускає Claude Desktop у фоні, коли даним близько п'яти хвилин. Авторизований запит виконує сам Claude; після появи свіжих даних AI Limit Bar закриває лише прихований екземпляр, який запустив сам. На практиці відсоток оновлюється приблизно кожні 5-6 хвилин. Кеш не містить часу скидання, тому панель показує час оновлення. Дані, старші за п'ять хвилин, не обираються для головного індикатора.

Використання Claude Code у підтримуваній IDE може враховуватися в тих самих лімітах підписки, а AI Limit Bar читає кеш Claude Desktop. Автоматичне фонове оновлення прибирає потребу відкривати Desktop вручну. Сторонні IDE-розширення з API-провайдером можуть мати окремі оплату та ліміти.

## Установлення

Потрібна macOS 13+, Codex для лімітів Codex і Claude Desktop для лімітів Claude. Завантажте `AI-Limit-Bar-2.3.1.dmg` з [останнього релізу](https://github.com/Vitashka2001/ai-limit-bar/releases/latest), перетягніть **AI Limit Bar** до `Applications` і запустіть.

Збірка локально підписана, але не нотаризована. Якщо macOS заблокує перший запуск, натисніть застосунок правою кнопкою, виберіть **Відкрити** й підтвердьте.

## Керування

- **Моніторинг лімітів** призупиняє всі фонові оновлення.
- **Оновлювати дані Claude у фоні** керує автоматичними прихованими запусками Claude Desktop.
- **Змінити обліковий запис Codex...** відкриває офіційний вхід Codex.
- **Змінити обліковий запис Claude...** відкриває налаштування профілю Claude Desktop для виходу та зміни облікового запису.
- **Мова** змінює мову інтерфейсу й перезапускає застосунок.
- **Запускати під час входу** керує автозапуском.
- **Повністю вимкнути** закриває застосунок.

Для повного вимкнення зніміть **Запускати під час входу** та виберіть **Повністю вимкнути**. Щоб увімкнути знову, відкрийте застосунок з `Applications`.
