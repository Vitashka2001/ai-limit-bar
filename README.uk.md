<h1 align="center">AI Limit Bar</h1>
<p align="center">Ліміти Codex і Claude в рядку меню macOS.</p>
<p align="center"><a href="README.md">English</a> · <strong>Українська</strong> · <a href="README.ru.md">Русский</a></p>

AI Limit Bar показує найактуальніший свіжий ліміт у рядку меню, а після відкриття — усі знайдені ліміти Codex і Claude в одній нативній панелі.

## Можливості

- автоматично стежить за нещодавньою активністю Codex або Claude;
- показує Codex і Claude поруч, коли обидва були активні протягом поточної 30-хвилинної робочої сесії;
- завжди надає перевагу свіжому критичному ліміту нижче 20%;
- показує всі знайдені 5-годинні й тижневі квоти;
- показує дату й час скидання кожного ліміту, коли Codex або Claude Code їх передає;
- дає змогу приховати Codex або Claude одночасно з панелі та індикатора рядка меню;
- зелений колір при 50–100%, жовтий при 20–49% і червоний нижче 20%;
- дає змогу змінювати Codex і відкриває налаштування профілю Claude Desktop для зміни облікового запису;
- отримує актуальні ліміти через офіційний інтерфейс рядка стану Claude Code;
- об'єднує всі локальні джерела Claude, тому відсоток з одного й час скидання з іншого показуються разом;
- пропонує офіційну інструкцію Claude Code і завантаження Desktop, коли джерело актуальних лімітів відсутнє;
- продовжує показувати останній відомий ліміт Claude замість прочерку й спорожнює вікно, коли його час скидання минув;
- англійська, українська та російська мови;
- ручне оновлення, пауза моніторингу й автозапуск.

## Джерела даних

Дані Codex надходять із локального `codex app-server`. Для Claude основним джерелом є офіційний інтерфейс [`statusLine`](https://code.claude.com/docs/en/statusline) Claude Code. Коли поточний режим Claude Code запускає рядок стану, після відповіді він передає відсотки й час скидання 5-годинного та тижневого лімітів. AI Limit Bar зберігає лише ці значення й одразу оновлює рядок меню.

Один раз увімкніть **Автооновлення Claude**, щоб додати локальний bridge до `~/.claude/settings.json`. Він встановлюється разом з офіційною опцією Claude Code `refreshInterval`, тому ліміти надходять кожні 30 секунд, поки сесія відкрита, а не лише після відповіді. Поля лімітів доступні підписникам Claude.ai Pro/Max у режимі Claude Code, який запускає `statusLine`; бічна панель VS Code може її не запускати, і цей випадок закривають два інші джерела. Bridge не виконує мережевих запитів і не читає паролі, OAuth-токени, cookies або API-ключі. Якщо рядок стану вже налаштовано, AI Limit Bar не замінює його.

Прогалини закривають ще два локальні джерела: `plan-usage-history.json` Claude Desktop, який той переписує приблизно раз на 15 хвилин під час роботи, і запис `cachedUsageUtilization`, який Claude Code зберігає в `~/.claude.json` і який переживає і закриту сесію, і закритий Desktop. Усі три об'єднуються по вікнах: перемагає найсвіжіший відсоток, а час скидання зі старішого джерела підставляється, поки він ще попереду. Жодне з них не оновлюється за розкладом, тому AI Limit Bar показує останнє відоме значення замість порожнього індикатора: ліміт не змінюється, поки Claude простоює, а вікно з минулим часом скидання знову показується порожнім. Сторонні IDE-розширення, наприклад Cline, можуть використовувати окремий API-білінг і не передавати ліміти підписки Claude.ai.

## Установлення

Потрібна macOS 13+, Codex для лімітів Codex і офіційний Claude Code для актуальних лімітів Claude або Claude Desktop як резерв. Завантажте `AI-Limit-Bar-2.5.0.dmg` з [останнього релізу](https://github.com/Vitashka2001/ai-limit-bar/releases/latest), перетягніть **AI Limit Bar** до `Applications` і запустіть.

Збірка локально підписана, але не нотаризована. Якщо macOS заблокує перший запуск, натисніть застосунок правою кнопкою, виберіть **Відкрити** й підтвердьте.

## Керування

- **Моніторинг лімітів** призупиняє всі фонові оновлення.
- **Відображувані сервіси** приховує Codex або Claude й припиняє опитування цього сервісу. Щонайменше один сервіс завжди залишається ввімкненим.
- **Автооновлення Claude** встановлює bridge рядка стану Claude Code, щоб ліміти надходили просто під час сесії.
- **Змінити обліковий запис Codex...** відкриває офіційний вхід Codex.
- **Змінити обліковий запис Claude...** відкриває налаштування профілю Claude Desktop. Без Desktop пункт **Налаштувати відстеження Claude...** запропонує офіційну інструкцію Claude Code й завантаження Desktop.
- **Мова** змінює мову інтерфейсу й перезапускає застосунок.
- **Запускати під час входу** керує автозапуском.
- **Повністю вимкнути** закриває застосунок.

Для повного вимкнення зніміть **Запускати під час входу** та виберіть **Повністю вимкнути**. Щоб увімкнути знову, відкрийте застосунок з `Applications`.

Якщо джерело Claude не налаштовано, рекомендація автоматично з'являється лише один раз під час першого запуску. Пізніше її можна відкрити вручну через **Налаштувати відстеження Claude...**, але звичайне оновлення саме її не показує.
