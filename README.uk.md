<h1 align="center">AI Limit Bar</h1>
<p align="center">Ліміти Codex і Claude в рядку меню macOS.</p>
<p align="center"><a href="README.md">English</a> · <strong>Українська</strong> · <a href="README.ru.md">Русский</a></p>

AI Limit Bar показує найактуальніший свіжий ліміт у рядку меню, а після відкриття — усі знайдені ліміти Codex і Claude в одній нативній панелі.

## Можливості

- автоматично стежить за нещодавньою активністю Codex або Claude;
- показує Codex і Claude поруч, коли обидва були активні протягом поточної 30-хвилинної робочої сесії;
- завжди надає перевагу свіжому критичному ліміту нижче 20%;
- показує всі знайдені 5-годинні й тижневі квоти;
- зелений колір при 50–100%, жовтий при 20–49% і червоний нижче 20%;
- дає змогу змінювати Codex і відкриває налаштування профілю Claude Desktop для зміни облікового запису;
- отримує актуальні ліміти через офіційний інтерфейс рядка стану Claude Code;
- ненадовго запускає Claude Desktop лише як резерв, якщо свіжі дані Claude Code недоступні;
- пропонує офіційну інструкцію Claude Code і завантаження Desktop, коли джерело актуальних лімітів відсутнє;
- чітко позначає застарілі дані Claude;
- англійська, українська та російська мови;
- ручне оновлення, пауза моніторингу й автозапуск.

## Джерела даних

Дані Codex надходять із локального `codex app-server`. Для Claude основним джерелом є офіційний інтерфейс [`statusLine`](https://code.claude.com/docs/en/statusline) Claude Code. Коли поточний режим Claude Code запускає рядок стану, після відповіді він передає відсотки й час скидання 5-годинного та тижневого лімітів. AI Limit Bar зберігає лише ці значення й одразу оновлює рядок меню.

Один раз увімкніть **Автооновлення Claude**, щоб додати локальний bridge до `~/.claude/settings.json`. Поля лімітів доступні підписникам Claude.ai Pro/Max після першої відповіді в режимі Claude Code, який запускає `statusLine`. Бічна панель VS Code може її не запускати; тоді резерв через Desktop вмикається автоматично. Bridge не виконує мережевих запитів і не читає паролі, OAuth-токени, cookies або API-ключі. Якщо рядок стану вже налаштовано, AI Limit Bar не замінює його.

Якщо свіжі дані Claude Code недоступні, автооновлення може ненадовго запустити Claude Desktop без активації й прочитати `plan-usage-history.json`. AI Limit Bar одразу приховує процес, повертає фокус попередньому застосунку, якщо Electron усе ж його запросив, і закриває лише запущений ним процес після отримання даних або через 30 секунд. Якщо Desktop уже працює, другого запуску не буде. Якщо його не встановлено, резервний спосіб просто пропускається. Сторонні IDE-розширення, наприклад Cline, можуть використовувати окремий API-білінг і не передавати ліміти підписки Claude.ai.

## Установлення

Потрібна macOS 13+, Codex для лімітів Codex і офіційний Claude Code для актуальних лімітів Claude або Claude Desktop як резерв. Завантажте `AI-Limit-Bar-2.4.4.dmg` з [останнього релізу](https://github.com/Vitashka2001/ai-limit-bar/releases/latest), перетягніть **AI Limit Bar** до `Applications` і запустіть.

Збірка локально підписана, але не нотаризована. Якщо macOS заблокує перший запуск, натисніть застосунок правою кнопкою, виберіть **Відкрити** й підтвердьте.

## Керування

- **Моніторинг лімітів** призупиняє всі фонові оновлення.
- **Автооновлення Claude** надає перевагу свіжим даним Claude Code, а Desktop використовує лише як резерв.
- **Змінити обліковий запис Codex...** відкриває офіційний вхід Codex.
- **Змінити обліковий запис Claude...** відкриває налаштування профілю Claude Desktop. Без Desktop пункт **Налаштувати відстеження Claude...** запропонує офіційну інструкцію Claude Code й завантаження Desktop.
- **Мова** змінює мову інтерфейсу й перезапускає застосунок.
- **Запускати під час входу** керує автозапуском.
- **Повністю вимкнути** закриває застосунок.

Для повного вимкнення зніміть **Запускати під час входу** та виберіть **Повністю вимкнути**. Щоб увімкнути знову, відкрийте застосунок з `Applications`.
