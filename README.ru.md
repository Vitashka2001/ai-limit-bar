<h1 align="center">AI Limit Bar</h1>
<p align="center">Лимиты Codex и Claude в строке меню macOS.</p>
<p align="center"><a href="README.md">English</a> · <a href="README.uk.md">Українська</a> · <strong>Русский</strong></p>

AI Limit Bar показывает наиболее актуальный свежий лимит в строке меню, а при открытии — все найденные лимиты Codex и Claude в одной нативной панели.

## Возможности

- автоматически следует за недавней активностью Codex или Claude;
- показывает Codex и Claude рядом, когда оба были активны в течение текущей 30-минутной рабочей сессии;
- всегда отдаёт приоритет свежему критическому лимиту ниже 20%;
- показывает все найденные 5-часовые и недельные квоты;
- зелёный цвет при 50–100%, жёлтый при 20–49% и красный ниже 20%;
- позволяет переключать Codex и открывает настройки профиля Claude Desktop для смены аккаунта;
- может ненадолго запускать Claude Desktop в фоне для обновления кеша лимитов;
- явно помечает устаревшие данные Claude;
- английский, украинский и русский языки;
- ручное обновление, пауза мониторинга и автозапуск.

## Источники данных

Данные Codex приходят из локального `codex app-server`. Данные Claude читаются из локального кэша Claude Desktop `plan-usage-history.json`. Приложение не читает cookies, session storage, пароли, токены или API-ключи.

Когда включено **Обновлять данные Claude в фоне**, AI Limit Bar ненадолго запускает Claude Desktop в фоне, как только кеш устареет. Авторизованный запрос выполняет сам Claude; после появления свежих данных AI Limit Bar закрывает только скрытый экземпляр, который запустил сам. В кеше нет времени сброса, поэтому панель показывает время обновления. Данные старше 15 минут не выбираются для главного индикатора.

Использование Claude Code в поддерживаемой IDE может учитываться в тех же лимитах подписки, а AI Limit Bar читает кеш Claude Desktop. Автоматическое фоновое обновление убирает необходимость открывать Desktop вручную. У сторонних IDE-расширений с API-провайдером могут быть отдельные оплата и лимиты.

## Установка

Требуется macOS 13+, Codex для лимитов Codex и Claude Desktop для лимитов Claude. Скачайте `AI-Limit-Bar-2.3.0.dmg` из [последнего релиза](https://github.com/Vitashka2001/ai-limit-bar/releases/latest), перетащите **AI Limit Bar** в `Applications` и запустите.

Сборка локально подписана, но не нотарифицирована. Если macOS заблокирует первый запуск, нажмите приложение правой кнопкой, выберите **Открыть** и подтвердите.

## Управление

- **Мониторинг лимитов** ставит все фоновые обновления на паузу.
- **Обновлять данные Claude в фоне** управляет автоматическими скрытыми запусками Claude Desktop.
- **Сменить аккаунт Codex...** открывает официальный вход Codex.
- **Сменить аккаунт Claude...** открывает настройки профиля Claude Desktop для выхода и смены аккаунта.
- **Язык** меняет язык интерфейса и перезапускает приложение.
- **Запускать при входе** управляет автозапуском.
- **Полностью выключить** закрывает приложение.

Для полного отключения снимите **Запускать при входе** и выберите **Полностью выключить**. Для включения снова откройте приложение из `Applications`.
