<h1 align="center">AI Limit Bar</h1>
<p align="center">Лимиты Codex и Claude в строке меню macOS.</p>
<p align="center"><a href="README.md">English</a> · <a href="README.uk.md">Українська</a> · <strong>Русский</strong></p>

AI Limit Bar показывает наиболее актуальный свежий лимит в строке меню, а при открытии — все найденные лимиты Codex и Claude в одной нативной панели.

## Возможности

- автоматически следует за недавней активностью Codex или Claude;
- показывает Codex и Claude рядом, когда оба были активны в течение текущей 30-минутной рабочей сессии;
- всегда отдаёт приоритет свежему критическому лимиту ниже 20%;
- показывает все найденные 5-часовые и недельные квоты;
- показывает дату и время сброса каждого лимита, когда Codex или Claude Code их передаёт;
- позволяет скрыть Codex или Claude одновременно из панели и индикатора строки меню;
- зелёный цвет при 50–100%, жёлтый при 20–49% и красный ниже 20%;
- позволяет переключать Codex и открывает настройки профиля Claude Desktop для смены аккаунта;
- примерно раз в минуту получает живые лимиты Claude через вход самого Claude Code — так же, как отслеживается Codex;
- объединяет все локальные источники Claude, поэтому процент из одного и время сброса из другого показываются вместе;
- предлагает официальную инструкцию Claude Code и загрузку Desktop, когда источник актуальных лимитов отсутствует;
- продолжает показывать последний известный лимит Claude вместо прочерка и обнуляет окно, когда его время сброса прошло;
- английский, украинский и русский языки;
- ручное обновление, пауза мониторинга и автозапуск.

## Источники данных

Данные Codex приходят из локального `codex app-server`.

Для Claude основным источником служит живой запрос к `api.anthropic.com/api/oauth/usage` — тот же, что стоит за командой `/usage` в Claude Code. Он отправляется примерно раз в минуту, сразу после выхода из сна и при открытии меню. Аутентификация — через вход самого Claude Code, прочитанный из связки ключей тем же инструментом `/usr/bin/security`, которым пользуется Claude Code, поэтому диалог связки ключей не появляется. Используется только access token; приложение никогда не обновляет вход само, потому что это разлогинило бы Claude Code. Когда токен истекает, пока Claude Code закрыт, приложение просит Claude Code обновить собственный вход, запуская в фоне его локальную команду `/usage` — без запроса к модели, без затрат, без сохранённой сессии, — так что живые лимиты поступают, даже когда Claude используется в другом месте, например на claude.ai или на удалённой машине. Что именно читается и отправляется — см. [PRIVACY.ru.md](PRIVACY.ru.md).

Локальные источники поддерживают индикатор, пока живой запрос не может выполниться: запись `cachedUsageUtilization`, которую Claude Code хранит в `~/.claude.json` (обновляется примерно раз за промпт), `plan-usage-history.json` Claude Desktop (переписывается только пока его окно используется) и официальный bridge [`statusLine`](https://code.claude.com/docs/en/statusline) Claude Code, установленный с `refreshInterval`, так что терминальная сессия отчитывается каждые 30 секунд. Боковая панель VS Code строку статуса не запускает. Все источники объединяются по окнам: побеждает самый свежий процент, а время сброса из более старого источника подставляется, пока оно ещё впереди. AI Limit Bar показывает последнее известное значение вместо пустого индикатора, а окно с прошедшим временем сброса снова показывается пустым.

Когда панель переходит на локальный источник, строка статуса объясняет почему — например, что живые лимиты возобновятся после запуска Claude Code. Сторонние IDE-расширения, например Cline, могут использовать отдельный API-биллинг и не передавать лимиты подписки Claude.ai.

## Установка

Требуется macOS 13+, Codex для лимитов Codex и официальный Claude Code для актуальных лимитов Claude либо Claude Desktop как резерв. Скачайте `AI-Limit-Bar-2.6.0.dmg` из [последнего релиза](https://github.com/Vitashka2001/ai-limit-bar/releases/latest), перетащите **AI Limit Bar** в `Applications` и запустите.

Сборка локально подписана, но не нотарифицирована. Если macOS заблокирует первый запуск, нажмите приложение правой кнопкой, выберите **Открыть** и подтвердите.

## Управление

- **Мониторинг лимитов** ставит все фоновые обновления на паузу.
- **Отображаемые сервисы** скрывает Codex или Claude и прекращает опрос этого сервиса. Как минимум один сервис всегда остаётся включённым.
- **Автообновление Claude** включает живые лимиты Claude и bridge строки статуса; выключение останавливает все запросы к Anthropic.
- **Сменить аккаунт Codex...** открывает официальный вход Codex.
- **Сменить аккаунт Claude...** открывает настройки профиля Claude Desktop. Без Desktop пункт **Настроить отслеживание Claude...** предложит официальную инструкцию Claude Code и загрузку Desktop.
- **Язык** меняет язык интерфейса и перезапускает приложение.
- **Запускать при входе** управляет автозапуском.
- **Полностью выключить** закрывает приложение.

Для полного отключения снимите **Запускать при входе** и выберите **Полностью выключить**. Для включения снова откройте приложение из `Applications`.

Если источник Claude не настроен, рекомендация автоматически показывается только один раз при первом запуске. Позже её можно открыть вручную через **Настроить отслеживание Claude...**, но обычное обновление само её не показывает.
